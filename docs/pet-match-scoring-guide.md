# 나에게 맞는 반려동물 찾기 - 품종 추천 점수 기준

## 1. 목적과 사용 범위

이 문서는 `나에게 맞는 반려동물 찾기`의 8개 질문 답변을 품종별 추천 점수로 바꾸기 위한 기준이다.

- 결과는 입양 가능 여부를 판정하지 않는 **참고용 추천**이다.
- 견종의 개체별 성격, 성장 환경, 훈련 경험, 건강 상태는 다를 수 있다.
- 추천 결과에는 1순위만 단정하지 않고 `추천 1순위`, `함께 검토할 품종`, `입양 전 확인할 점`을 함께 표시한다.
- 건강 정보는 품종을 감점하는 기준으로 쓰지 않고, 결과의 확인 사항으로만 안내한다.

## 2. 점수 축

사용자와 품종 모두 아래 7개 축을 1~5점으로 표현한다. 숫자가 같을수록 적합도가 높다.

| 축 | 1점 | 3점 | 5점 |
|---|---|---|---|
| 활동량 | 짧고 가벼운 산책 중심 | 매일 산책·놀이 필요 | 긴 산책·운동·자극이 매우 중요 |
| 교감 욕구 | 독립적인 시간도 편안함 | 보호자와 균형 있는 교감 | 사람과 함께하는 시간 선호 |
| 혼자 지내기 | 혼자 있는 시간이 길면 어려움 | 짧은 외출은 가능 | 비교적 독립적인 생활 가능 |
| 사회화·외부 자극 | 조용하고 예측 가능한 환경 선호 | 상황에 따라 적응 | 사람·동물·외부 활동을 즐김 |
| 훈련·지적 자극 | 기본 생활 훈련 중심 | 규칙적인 훈련 가능 | 훈련·과제·놀이 자극을 많이 원함 |
| 공간 요구 | 소형 주거에서도 생활 가능 | 산책로가 있으면 적응 | 넓은 공간과 야외활동이 중요 |
| 털 관리 수용도 | 적은 관리 선호 | 주 1~2회 관리 가능 | 빗질·미용을 꾸준히 할 수 있음 |

## 5. 추천 계산 방식

### 5.1 기본 적합도

품종별로 아래 점수를 계산한다.

```text
축별 적합도 = 5 - |사용자 축 점수 - 품종 축 점수|
기본 점수 = 모든 축별 적합도의 합계
```

중요도가 높은 축은 가중치를 적용한다.

| 축 | 가중치 |
|---|---:|
| 활동량 | 1.5 |
| 교감 욕구 | 1.5 |
| 혼자 지내기 | 1.5 |
| 공간 요구 | 1.5 |
| 사회화·외부 자극 | 1.0 |
| 훈련·지적 자극 | 1.0 |
| 털 관리 수용도 | 1.0 |

### 5.2 필수 조건 감점

아래 조건은 사용자의 생활 여건과 충돌이 큰 경우에만 적용한다.

| 조건 | 처리 |
|---|---|
| 실내 공간이 매우 제한적이고 활동량이 낮음 | 공간 요구 4~5인 품종에 -8점 |
| 혼자 있는 시간이 많음 | 교감 5·독립 1~2인 품종에 -8점 |
| 훈련·활동 시간이 충분함 | 훈련 4~5인 품종에 +3점 |
| 털 관리 부담을 감수하기 어려움 | 관리 5인 품종에 -6점 |
| 야외 활동을 자주 원함 | 활동 4~5인 품종에 +3점 |

### 5.3 입양 준비도 경고 결과

아래 중 하나라도 해당하면 품종 순위를 바로 보여주지 않고, 안내 화면을 먼저 보여준다.

- Q3에서 `현재는 매우 바쁘다` 선택
- Q7에서 `계획이 자주 바뀌어 돌봄 계획이 어렵다` 선택
- Q5에서 `짧은 돌봄 루틴이 현실적이다`를 선택하면서 Q1 또는 Q4에서 높은 활동량을 선택

표시 문구 예시:

> 현재 생활 패턴에서는 특정 품종보다 돌봄 시간과 비상시 돌봄 계획을 먼저 점검하는 것이 좋아요. 준비가 된 뒤 다시 테스트해 보세요.

## 6. 결과 화면 규칙

1. 최종 점수가 높은 품종 3개를 정렬한다.
2. 1위 품종을 `가장 잘 맞는 반려견`으로 표시한다.
3. 2~3위는 `함께 검토할 품종`으로 표시한다.
4. 사용자의 높은 점수 축과 1위 품종의 일치 축 2~3개를 `잘 맞는 이유`로 만든다.
5. 1위 품종의 관리·운동·훈련 관련 축 중 점수가 가장 크게 차이 나는 항목을 `입양 전 확인할 점`으로 만든다.

### 결과 문구 예시

```text
당신에게 가장 잘 맞는 반려견은 ‘골든 리트리버’예요.

잘 맞는 이유
- 규칙적인 산책과 놀이 시간을 낼 수 있어요.
- 사람 및 다른 반려동물과 교류하는 활동을 선호해요.
- 보호자와의 교감과 훈련을 즐기는 편이에요.

함께 검토할 품종
래브라도 리트리버 · 아메리칸 코커스패니얼

입양 전 확인할 점
매일 산책·놀이 시간을 꾸준히 확보할 수 있는지 확인해 주세요.
```

## 7. 구현 데이터 구조 권장안

```java
class BreedProfile {
    String name;
    int activity;
    int bonding;
    int independence;
    int socialization;
    int training;
    int space;
    int grooming;
    String[] strengths;
    String[] considerations;
}
```

`PetMatchActivity`는 선택지별로 사용자 축 점수를 누적하고, 마지막 질문 뒤 각 `BreedProfile`과 비교해 상위 3개를 결과 화면에 전달한다.
