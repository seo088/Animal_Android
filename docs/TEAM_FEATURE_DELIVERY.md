# 팀 작업 인수인계

## 역할

| 담당 | 범위 | 완료 기준 |
| --- | --- | --- |
| 사용자님 | 백엔드·지식그래프 데이터 | 원본 ID 보존, API 검증, `Backend` 푸시 |
| 현수 선배 | Android 프론트엔드·반려동물 테스트 | 화면·상태 처리·기기 검증 |
| 경빈 선배 | 코드 병합·통합 확인 | 변경사항 검토, 충돌 해결, 최종 빌드 확인 |

## 현재 병렬 작업

| 작업 | 담당 | 상태 |
| --- | --- | --- |
| 증상 지식그래프 라벨 정규화 | 사용자님 | 검토 목록 완료 |
| 반려동물 궁합·맞춤 찾기·MBTI 화면 | 현수 선배 | 진행 중 |
| 기능 단위 병합과 Backend 반영 확인 | 경빈 선배 | 대기 |

## 지식그래프 작업 규칙

- 현재 앱 API `/symptoms`가 노출하는 증상은 13개다.
- 원본 Turtle의 증상 ID와 원문 라벨은 보존한다.
- 쉼표가 있다고 자동으로 증상을 분리하지 않는다.
- 임상적으로 다른 징후의 분리는 수의 검토 후에만 반영한다.
- 백엔드 변경 후 `/symptoms`, `/diagnosis/infer`, 앱 증상 선택을 확인한다.
